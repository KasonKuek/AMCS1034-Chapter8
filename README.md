# Python GUI Lab (AMCS1034 Chapter 8)

A learning site for students: graphical user interfaces with tkinter.

- **Learn**: 15 sections following the slides (GUI and events, widgets, buttons and handlers, properties,
  tkinter variables, canvas, images, pack/grid, menus, mouse and key events, animation, dialogs, review),
  with an anchor picker, a canvas coordinate demo and a pack-manager playground
- **GUI Lab**: 28 runnable tkinter examples from the slides. The code runs in the browser and the window
  opens on the page (buttons, entries, canvas, menus, mouse/key events, animation, dialogs).
  The same code runs unchanged on your own computer.
- **Quiz**: 35 multiple-choice questions with explanations
- **Exam Practice**: 10 structured questions with model answers

Live site: https://kasonkuek.github.io/AMCS1034-Chapter8/
